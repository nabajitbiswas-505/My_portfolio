# 💼 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built using **HTML5, CSS3, and JavaScript**. The portfolio showcases my skills, projects, education, certifications, and contact information with smooth animations and a clean UI.

---

## 🚀 Features

- 🎨 Modern and responsive design
- 🌙 Light/Dark theme toggle
- ✨ Smooth scrolling and animations
- 📊 Animated skill progress bars
- 💻 Project showcase section
- 📚 Education timeline
- 🏆 Certifications & achievements
- 📱 Fully responsive for desktop, tablet, and mobile
- 🔗 GitHub, LinkedIn, Email, and Coding Profile links
- ⚡ Fast loading and lightweight

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts
- CSS Animations
